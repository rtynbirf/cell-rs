# ADR-0001: Rust-клетка-росток — ядро без зависимостей

- Статус: принято
- Дата: 2026-11-08
- Контекст: дорожная карта роя, пункт «первая Rust-клетка». Ворклог TH-RTP-05
  (H-PE11-PHOENIX).

## Проблема

Все клетки роя — Python. Rust даёт: память без сборщика (контур сверки без
утечки карты в случайные байты), исполнение в ядре Linux (тренд 2024–2026),
выхоленный бинарь для суверенных хостов (cell65-host). Но полноценно тащить
serde/json в клетку-росток — тащить тело раньше сердца.

## Решение

Клетка-росток v0.1: ТОЛЬКО ядро, ноль зависимостей.

1. `Tolerance {eps, deadband}` + `reconcile()` — семантика ОДИН-В-ОДИН с
   Python-ядром; приёмки гоняют те же векторы (0.505/0.53/0.60 против
   eps=0.05, deadband=0.02). Кровь одна во всех телах — начиная с семантики.
2. `sha256` с нуля (FIPS 180-4), приёмки на векторах NIST (пустая строка,
   "abc", двухблочный вектор). Клетка не верит чужому хешу — она сама хеш.
3. Байт-цепь `seal_line`/`verify_chain` (генезис 64 нуля): подмена середины,
   разрыв и застой seq ловятся приёмками.
4. Компилятор клетки — CI GitHub Actions (rust toolchain предустановлен на
   раннере): красный прогон = клетка больна. Честно заявлено, не притворяемся
   локальной сборкой.

## Следствия

- JSON-конверт крови (канон blood.py) — следующий шаг, только с serde и
  отдельным ADR: сериализация ≠ семантика, растут по очереди.
- Пин клетки входит в геном cell-swarm живым SHA (не по памяти).
- Зависимости добавляются только через ADR (AGENTS.md, запрет без решения).

## Приёмки

`cargo test`: векторы NIST ×3, цепь (сборка/подделка/разрыв/застой/пустая),
совместимость семантики с Python-ядром, границы допуска.
